# Site de Présentation - Cycle de Vie Logiciel

Site web responsive présentant une vidéo éducative sur le cycle de vie d'une application logicielle, avec un design antique inspiré des manuscrits anciens.

## Aperçu

Un site minimaliste et élégant pour visionner une présentation vidéo hébergée sur YouTube. Design épuré centré sur la vidéo.

## Design

- **Style antique** : fond parchemin avec texture, bordures dorées, tons sépia
- **Responsive** : s'adapte à tous les écrans (mobile, tablette, desktop)
- **Typographie classique** : Georgia / Times New Roman
- **Cadre vidéo** : bordures burgundy profond rappelant le velours des manuscrits

## Technologies

- **HTML5**
- **CSS3** (responsive, dégradés, pseudo-éléments)
- **YouTube Embed** pour la lecture vidéo

## Structure

```
├── index.html    # Page principale
├── style.css     # Design antique responsive
└── README.md     # Documentation
```

## Utilisation

1. Clonez le dépôt
2. Ouvrez `index.html` dans un navigateur
3. La vidéo YouTube se charge automatiquement

## Objectif

Présenter les étapes du cycle de vie logiciel : analyse des besoins, conception, développement, tests, déploiement et maintenance.
